# SpaceInvadersPyGame
> A project to learn how to build [Space Invaders](https://en.wikipedia.org/wiki/Space_Invaders) in pygame.

## Description
Built on python using the pygame package.
A similar recreation of the Space Invader Game.

## Missing Component
- A starting screen for the game
